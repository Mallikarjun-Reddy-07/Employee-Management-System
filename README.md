
# EMS - Day 5: Employee CRUD Operations

This repository contains the **Day 5** work of the Employee Management System (EMS) learning series.

On Day 5, I implemented **Employee CRUD operations** using Spring Boot, Spring Data JPA, Hibernate, MySQL, and REST APIs.

---

## 📚 Day 5 Topic

### Employee CRUD Operations

CRUD stands for:

- **C** - Create
- **R** - Read
- **U** - Update
- **D** - Delete

The project implements all four operations for managing employee records.
